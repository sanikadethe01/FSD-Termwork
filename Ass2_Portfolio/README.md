# Assignment 2: Personal Portfolio Website

## Problem Statement
Design and develop a personal portfolio website that presents personal details, skills, projects, and contact information in an organized and visually appealing manner.

## Objective
- To design a personal portfolio webpage using HTML and CSS.
- To practice webpage layout and styling techniques.
- To present personal information and projects in a structured format.
- To improve front-end development skills.

## Technologies Used
- HTML
- CSS

## Description
This assignment focuses on creating a personal portfolio website that highlights an individual's profile, skills, and projects. The webpage includes different sections such as personal information, skills, projects, and contact details.

HTML is used to structure the webpage content, while CSS is used to enhance the design and layout of the webpage, making it visually appealing and easy to navigate.

## Features
- Displays personal profile information.
- Includes sections for skills, projects, and contact details.
- Clean and simple webpage layout.
- Styled using CSS for improved user interface.
